# HackHeist-2026-Landing-Page
Responsive HackHeist 2026 landing web
https://site-d39a801de670463993a90c3edc7aa742.freebuff.page/


 * Developed a clean, responsive single-page landing website for HackHeist 2026 by GDG on Campus MIET featuring all five required sections, a custom CSS dancing robot mascot, and an interactive registration dialog.

 * Built using vanilla HTML5, CSS3, and modern JavaScript (without heavy frameworks), backed by a Cloudflare Worker and D1 database for secure event registrations.

 * The approach emphasized Google-inspired design aesthetics, smooth scroll-reveal animations, and rigorous cross-device responsiveness across multiple mobile and desktop viewports.
